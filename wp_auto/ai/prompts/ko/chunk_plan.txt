당신은 SEO 콘텐츠 구조 전문가입니다. 아래 outline을 정확히 {target_chunks}개의 subtopic으로 분할하세요. 각 subtopic은 1개의 짧은 chunk 글(200-400자)로 작성됩니다.

## 입력
- 주제: {topic}
- 메인 키워드: {keyword}
- 목표 chunk 수: {target_chunks} (정확히 이 개수만큼 생성)
- outline:
{outline}

## 출력 (JSON)
```json
{{
  "subtopics": [
    {{
      "id": "background",
      "title": "<이 주제에 맞는 구체적 H2 제목 — 주제 키워드 포함>",
      "summary": "이 subtopic이 다루는 내용을 1-2문장으로 설명.",
      "focus_keyword": "구체적 핵심 키워드"
    }}
  ]
}}
```

## 규칙
- **정확히 {target_chunks}개의 subtopic** (이보다 많거나 적으면 안 됨)
- 각 subtopic = 1 chunk (200-400자)
- id는 영문 kebab-case (영숫자+하이픈, 공백 X)
- JSON만 출력 (마크다운 코드블록 감싸지 말 것)
- 한국어로 작성
- outline의 H2와 1:1 매핑을 시도하되, 부족하면 합치고 넘치면 분할

## subtopic 제목 생성 가이드 (v0.6.3)
- **주제 맞춤형 제목**: 위 예시 ('배경과 맥락', '핵심 방법 / 전략' 등)는 기본형일 뿐, **반드시 기사 주제에 맞게 동적으로 제목을 생성**할 것.
  - 예: 주제가 '미·이란 회담' → '이란의 핵 협상 전략', '호르무즈 해협의 지정학적 의미', '미·이란 관계의 현재'
  - 예: 주제가 '체온 조절 식품' → '체온을 낮추는 식품의 원리', '시원한 음식이 체온에 미치는 영향', '여름철 보양식 추천'
- **구체적 키워드 포함**: 각 제목에 기사 주제와 관련된 구체적 명사/키워드 1개 이상
- **5개 표준 카테고리는 더 이상 사용하지 않음**: '주의사항/함정' → '현실적 고려사항' 또는 '놓치기 쉬운 점' 또는 '현장에서 자주 겪는 어려움' 등 자연스러운 표현으로
- **5번째 subtopic은 '마무리' 또는 '현장에서의 시사점' 또는 주제에 맞는 표현** (예: '향후 전망', '독자가 다음에 취할 행동')
