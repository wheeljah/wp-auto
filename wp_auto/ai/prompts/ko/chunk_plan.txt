당신은 SEO 콘텐츠 구조 전문가입니다. 아래 outline을 정확히 {target_chunks}개의 subtopic으로 분할하세요. 각 subtopic은 1개의 짧은 chunk 글(200-400자)로 작성됩니다.

## 입력
- 주제: {topic}
- 메인 키워드: {keyword}
- 목표 chunk 수: {target_chunks} (정확히 이 개수만큼 생성)
- outline:
{outline}

## 출력 (JSON)
```json
{{
  "subtopics": [
    {{
      "id": "background",
      "title": "배경과 맥락",
      "summary": "이 주제가 왜 중요한지, 독자가 알아야 할 기본 배경을 1-2문장으로 설명.",
      "focus_keyword": "구체적 핵심 키워드"
    }},
    {{
      "id": "method",
      "title": "핵심 방법 / 전략",
      "summary": "실행 가능한 핵심 방법 또는 전략을 1-2문장으로 요약.",
      "focus_keyword": "방법 관련 키워드"
    }},
    {{
      "id": "example",
      "title": "실제 사례 / 예시",
      "summary": "독자가 따라할 수 있는 구체적 예시나 실제 데이터를 1-2문장으로.",
      "focus_keyword": "사례 관련 키워드"
    }},
    {{
      "id": "caution",
      "title": "주의사항 / 함정",
      "summary": "흔한 실수나 함정, 주의할 점을 1-2문장으로.",
      "focus_keyword": "주의 관련 키워드"
    }},
    {{
      "id": "summary",
      "title": "정리 / 다음 단계",
      "summary": "핵심 결론과 독자가 다음에 취할 행동을 1-2문장으로.",
      "focus_keyword": "결론 관련 키워드"
    }}
  ]
}}
```

## 규칙
- **정확히 {target_chunks}개의 subtopic** (이보다 많거나 적으면 안 됨)
- 각 subtopic = 1 chunk (200-400자)
- id는 영문 kebab-case (영숫자+하이픈, 공백 X)
- JSON만 출력 (마크다운 코드블록 감싸지 말 것)
- 한국어로 작성
- outline의 H2와 1:1 매핑을 시도하되, 부족하면 합치고 넘치면 분할
