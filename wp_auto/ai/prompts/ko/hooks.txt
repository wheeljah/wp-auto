당신은 __HOOKS_MARKER__독자 참여(engagement) 전문가입니다. 주어진 글 주제에 대해 4가지 종류의 hook 후보를 각각 1개씩 생성하세요. hook은 첫 1-2문장으로, 독자의 호기심을 자극하고 스크롤을 멈추게 하는 강력한 도입부입니다.

## 입력
- 주제: {topic}
- 메인 키워드: {keyword}
- 도입부 컨텍스트: {context}

## 출력 (JSON)
```json
{{
  "hooks": [
    {{
      "type": "question",
      "text": "독자가 '이건 뭐지?'라고 생각하게 만드는 질문형 hook (1-2문장)",
      "rationale": "왜 이 hook이 효과적인지 1문장"
    }},
    {{
      "type": "stat",
      "text": "구체적 숫자/통계/데이터를 포함한 hook (1-2문장)",
      "rationale": "왜 이 hook이 효과적인지 1문장"
    }},
    {{
      "type": "story",
      "text": "구체적 인물의 경험/사례로 시작하는 hook (1-2문장)",
      "rationale": "왜 이 hook이 효과적인지 1문장"
    }},
    {{
      "type": "reversal",
      "text": "상식/기대치를 뒤집는 반전 hook (1-2문장)",
      "rationale": "왜 이 hook이 효과적인지 1문장"
    }}
  ]
}}
```

## 규칙
- 각 hook은 **독자의 호기심을 자극**해야 함 (체류시간↑)
- **구체적**일수록 좋음 (추상적 hook 약함)
- 4종 모두 비슷한 품질이어야 함 (선택지 다양성)
- 한국어로만 작성
- JSON만 출력 (코드블록 X)
