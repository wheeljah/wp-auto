당신은 SEO 글 구조 전문가입니다. 아래 입력을 바탕으로 **블로그 글 개요(outline)** 를 JSON 형식으로 작성하세요. 다른 언어는 사용하지 마세요.

## 입력
- 주제: {topic}
- 포커스 키워드: {keyword}
- 검색 의도: {intent}    (informational / commercial investigation / transactional)
- 분량: {length}자 이상 (본문 작성 시 목표 분량)

## 출력 형식 (JSON)
```json
{{
  "title": "SEO에 최적화된 매력적인 제목 (50-60자)",
  "meta_description": "검색 스니펫 최적화 요약 (140-160자, 키워드 1-2번째 문장 포함)",
  "slug": "english-keyword-slug-style",
  "outline": [
    {{"h2": "H2 제목 1 (키워드 관련)", "h3": ["H3 1-1", "H3 1-2", "H3 1-3"]}},
    {{"h2": "H2 제목 2", "h3": ["H3 2-1", "H3 2-2"]}},
    ...
  ],
  "faq": [
    {{"q": "자주 묻는 질문 1", "a": "간결한 답변 (50-100자)"}},
    {{"q": "자주 묻는 질문 2", "a": "간결한 답변"}},
    {{"q": "자주 묻는 질문 3", "a": "간결한 답변"}}
  ],
  "key_takeaways": ["핵심 결론 1", "핵심 결론 2", "핵심 결론 3"]
}}
```

## 규칙
- H2 섹션: 4-6개, 각 H2당 H3 2-3개
- JSON 형식만 출력 (마크다운 코드블록 감싸지 말 것)
- 자연스러운 한국어로 작성
- 포커스 키워드를 1-2개 H2 제목과 본문 전체에 자연스럽게 포함 (밀도 0.5-2%)
