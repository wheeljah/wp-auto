⚠️ 설정 변경 방법

# .env 예시
WP_SITE_URL=https://example.com
WP_USER=admin
WP_APP_PASSWORD=xxxx xxxx xxxx xxxx xxxx xxxx
WP_MOCK=false
OLLAMA_MODEL=llama3.1:8b
DB_PATH=./data/wp_auto.db
💡 시스템 명령어
  • python -m wp_auto doctor — 환경 진단
  • ollama list — 설치된 LLM 모델
  • python -m wp_auto list-posts — CLI로 글 목록
